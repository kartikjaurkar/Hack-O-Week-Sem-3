# Simple HTTP Server

A basic HTTP server built with Node.js's built-in `http` module.

## Features
- Handles multiple routes (`/`, `/about`, `/contact`)
- Returns HTML responses
- Handles 404 for unknown routes
- Runs on port 3000

## How to Run
```bash
node server.js
```

Then open your browser and navigate to:
- http://localhost:3000 - Home page
- http://localhost:3000/about - About page
- http://localhost:3000/contact - Contact page

## Requirements
- Node.js installed
